# 03 任务拆分（splitter）

> **TL;DR**
> 1. 共 **8 张卡**：A 线 3 张（T01-T03，infra-gpu）、B 线 2 张（T04-T05，algo）、C 线 2 张（T06-T07，dev）、收口 1 张（T08，dev）。
> 2. 依据 02 架构评审的 R1~R16：`--hidden/--layers`、mock golden 数值、`ratio` 单真值、AST 白名单、PyYAML、`safe_host`、纯函数 `parse_smi_csv` 全部落到卡内 DoD。
> 3. 关键路径：**T01 → T02 → T03 → T08**（4 卡）；B/C 两线完全并行，只等 T08 收口。
> 4. 三条线零代码依赖，唯一硬串行是「解析内核 → CLI 外壳 → 远程采集 → 全仓自检」。
> 5. 规模红线：A ≤ 520 行、B ≤ 380 行、C 合计 ≤ 900 行，超预算即停工复核（防范围蔓延）。
> 6. 每卡 DoD 都写成**可执行命令或可断言数值**，不写形容词；验收条目编号直接引用 PRD A-A*/B-A*/C-A*。

## 0. 全局约定（每卡默认继承，不再重复）

| 项 | 约定 |
|---|---|
| 语言/版本 | Python 3.9+，禁用 `match`、`X \| Y` 类型语法；类型用 `Optional[...]` / `List[...]` |
| 分层纪律 | `argparse → 纯函数内核 → 渲染 → main`；`main` 是唯一 `sys.exit` 出口 |
| 纯函数禁入 | `parse_*` / `estimate_*` / `verdict` / `validate_*` / `render_*` 内禁止 `print` / `open` / `subprocess` / 读时间戳 |
| 错误口径 | 只有两类异常：`UsageError`（exit 2）/ `CollectError`（exit 3）；文案 =「发生了什么 + 三条怎么办」；禁止裸 traceback |
| 零依赖 | A/B 两文件 AST 白名单扫描必须 `VIOLATION: none`（脚本见 02·R5） |
| 交付即自检 | 每卡提交前必须自跑该卡 DoD 命令并把输出贴进 PR 描述，不写「已自测」 |

## T04 · vram_est 五层数学模型内核（公式 / 三态 / 反向求解）

- **负责角色**：algo（算法工程师）
- **依赖**：无（与 A 线并行，M4 起点）
- **产出文件**
  - `src/vram_est.py`（本卡只写「常量 + `normalize` / `split_params` / 五个 `estimate_*` / `verdict` / `max_batch_size` / `FORMULAS` / `ASSUMPTIONS` 模板」，预算 ≤ 260 行）
- **DoD**
  1. `PRECISION_BPP = {fp32:4, fp16:2, bf16:2, int8:1, int4:0.5}`；`GRAD_BPP = 4`（恒 fp32）；`OPTIMIZER_BPP = 12`，`precision == "fp32"` 分支走 8（master 与参数共用），两分支均有注释。
  2. 单位统一 **GiB（2^30 B）**，模块内单一换算常量，禁止各处散写 `1024**3`。
  3. LoRA 单真值：`P_trainable = P_total * lora_target_ratio`（`lora_rank == 0` 时 `= P_total`）；`lora_rank` **不参与任何估算函数**，只在返回结构里带出用于一致性提示（R-双真值收敛）。
  4. 手算对齐（02·2.5.4 表，±5% 容差）：`--params 0.244 --hidden 768 --layers 12 --precision fp16 --lora-rank 8 --batch-size 8 --seq-len 3000` → `weights≈0.45 / grads≈0.002 / optimizer≈0.014 / activations≈1.65 / overhead≈0.52 / total≈2.64`。
  5. 不变量：`abs(sum(breakdown.values()) - total_gb) < 1e-6`（R4 并入 B-A6）。
  6. `verdict(total, target)`：`ratio<=0.85 → PASS`；`0.85<ratio<=1.00 → TIGHT`；`>1.00 → OOM`；端点归属用 `0.85` 与 `1.00` 各造一个用例断言（0.85 精确值 → PASS，1.00 精确值 → TIGHT）。
  7. `max_batch_size(input, target)`：闭式初值后用 L2 的 `estimate_*` 单调回退校验，**不得重写公式**；`b=1` 已超限 → `0`，并向 `assumptions` 追加「最小可行配置仍超限，需降 precision / 缩 seq_len / 换卡」。对手算场景断言 ≈ 111（±5%），`target=2` 断言 0。
  8. 全部系数标注 `# 来源：经验值（本仓库未实测），依据 <依据>，误差 ±xx%`；`act_factor` 条目写「每 token 每层保留的中间张量份数（含反向所需），误差 ±50%」；禁止「实测于 A100」类表述（K1 诚信红线）。
  9. `FORMULAS` 为常量字典（分项名 → 公式字符串），渲染层只读它，防文档与代码漂移（R15）。
  10. 纯函数内无 `print` / `open` / 时间戳；AST 白名单收紧到 `argparse/json/sys/typing/dataclasses/textwrap/math` 后 `VIOLATION: none`（B-A9）。
