## 二、关键裁决与门禁（跨文档共识，避免重复读）

- **R1 鉴权可配**：网关是反代可能要 `Authorization: Bearer`，故加 `--header "Key: Value"`，默认空；401 时提示加 header。密钥绝不写死代码（不变式 C）。
- **R2 离线 mock**：沙箱无 Tailscale 时 `--mock` 内置样例，三子命令零 socket 全链路可跑（CI/演示不依赖网络）。
- **R3 退出码/错误分级**：`0`成功（含降级完成）/ `1`业务不可用 / `2`参数错误 / `3`致命异常兜底；成功率<100% 非全失败 → 退出 0 标「降级」。`--json` 机器可读。
- **红线（一票否决）**：method 白名单仅 GET/HEAD；构造层拒绝 `data=`；无 os.environ/硬编码密钥；仅本地落盘 `--out`，绝不写回网关。

## 三、dev 必守不变式（实现校验清单，reviewer/qa 逐条核）

1. 限流默认开启不可关（Semaphore 封顶16，`--rate` 令牌桶可关）
2. p 分位用最近秩排序取位，禁均值替代
3. 估算值必带「**估算**」标签，不得与真实值混淆
4. 仅成功样本纳入延迟统计（超时/失败进成功率分母但不进延迟）
5. 超时即失败样本（URLError/socket.timeout 记失败，不重试）
6. 全程只读 GET（构造层拒绝写方法、禁账户/Web/告警）
