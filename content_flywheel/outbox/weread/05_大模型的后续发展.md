# 05 · 大模型的后续发展：五条主线与两个换血点

## 一句话

大模型没有"下一个 GPT 时刻"，只有五条并行主线在各自换挡：**推理与 RL、效率、多模态统一、Agent、世界模型**。谁在赌单点突破，谁就会错过这条火车。

---

## 主线一：推理与 RL——从"预测下一词"到"想对再答"

o1 / DeepSeek-R1 / Kimi k1.5 标记的转折：**把算力从预训练挪到推理时**（test-time compute scaling）。模型在回答前先长链条思考，思路链越长、答案越好——这是 2020 年 scaling law 之后第一个新的、可外推的 scaling 维度。

支撑它的关键工程是 **RLVR（可验证奖励的强化学习）**：数学、代码这类有标准答案的任务，奖励可以自动判——不需要人类标注偏好，直接对答案。R1 证明了纯 RL + 规则奖励也能长出长思考链。

**边界**：RLVR 只在"可验证"的任务上成立。写诗、咨询、开放对话没有 check 函数——这条主线的天花板就是"可验证任务"的覆盖率。下一阶段的稀缺资源由此从算力转向**可验证任务的构造能力**（这也是为什么"过程奖励模型"、"通用验证器"成为热点）。

## 主线二：效率——预训练 scaling 撞墙后的主战场

高质量文本数据逼近极限（数据墙），预训练的"堆卡堆数据"边际收益下降，效率成为主战场：

- **架构层**：MoE 稀疏化（万亿参数千亿激活）、线性注意力/SSM 挑战 O(N²)、GQA/MLA 压 KV；
- **推理层**：量化（FP8 → FP4）、投机解码、PD 分离（DistServe/Mooncake）、KV 分页管理；
- **训练层**：FP8 混合精度、通信优化。

判断：**Transformer 本体五年内不会换血，但它的"外围"已经全部换血**——注意力内核、KV 管理、并行策略、数值精度，没一样还是 2017 年的样子。属于"渐进式颠覆"。

## 主线三：多模态统一——从"外挂"到"原生"

第一代多模态是外挂（视觉编码器 + LLM 翻译）；下一代是**原生统一**：文本、图像、音频、视频全部切成 token 进一个 Transformer（时空 patch 范式已被 Sora 验证可扩展），出生即全模态。关键争论在"离散 token vs 连续 latent"：离散好采样但丢信息，连续保真但难自回归——这个拓扑问题还没解干净（《五道坎》第三章）。

## 主线四：Agent——从"回答问题"到"完成任务"

模型能力的最后一公里不在智力，在**可靠性**：长程任务中途一步错全盘崩。当前解法全是工程补丁：工具调用、ReAct 式规划、记忆外置（RAG/向量库）、子任务分解、多智能体互查。真正缺的是**长程 RL 的环境**——互联网就是环境，但太贵太乱。Agent 的成熟度=环境工程 + 可靠性工程，模型反而是其中最不卡脖子的部分。

## 主线五：世界模型与具身——从"背视频"到"可交互"

Sora 式的"视频生成=世界模型"叙事已退潮；接力棒交给了**交互式生成**（输入动作、输出下一帧状态，Genie 类）与**具身 VLA**（视觉-语言-动作模型 + 分层控制）。这一线最慢，因为它要同时跨《五道坎》的第三、四道坎（物理约束 + sim2real）。

## 两个换血点（我认为真正会改变格局的）

**换血点一：稀缺资源从算力换成"可验证任务与真实交互数据"。**
预训练时代拼数据爬取，RLVR 时代拼任务构造——谁能低成本造出"自动判对错"的高质量任务流（代码库、形式化环境、仿真器），谁就掌握新的 oil field。这解释了为什么数学/代码是主战场：它们是天然的可验证孤岛。

**换血点二：评测体系失效。**
Benchmark 污染（题目进了训练数据）+ 能力与 benchmark 脱钩，让"刷榜"的信息量归零。下一代评测必然走向**私有动态题库 + 真实任务完成率**——这也是 Agent 时代唯一诚实的指标。

## 风险清单（真实的，不是科技媒体那种）

1. **能耗**：训练一个前沿模型耗电已到吉瓦时级，推理侧随部署量指数涨——能源是比 GPU 更早到的硬约束。
2. **数据墙 → 合成数据的反噬**：RL 的 self-play 数据分布会越来越窄（只覆盖可验证任务），模型可能"数学越强、常识越偏"。
3. **安全与对齐**跟不上能力：模型会执行长程任务之后，对齐问题从"别说坏话"变成"别做错事"，后者难一个量级。

## 一张表收尾

| 主线 | 关键词 | 现状 | 卡点 |
|------|--------|------|------|
| 推理与 RL | test-time scaling、RLVR | 已验证可外推 | 可验证任务覆盖率 |
| 效率 | MoE、量化、PD 分离 | 工程繁荣 | 无单点突破，靠堆 |
| 多模态 | 原生统一、时空 patch | 范式已定 | 离散 vs 连续拓扑 |
| Agent | 工具、长程、记忆 | demo 多、可靠少 | 环境与可靠性工程 |
| 世界模型/具身 | 交互式生成、VLA | 早期 | 物理约束 + sim2real |

一句话总结：**大模型的下一步不是一次奇点，是五条 S 曲线的接力——而每条曲线的瓶颈都写在了《五道坎》里。**
