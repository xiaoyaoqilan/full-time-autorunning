# 01 · AI 是怎么生成图片的：把 DDPM 讲到你能自己推导

## 一句话

扩散模型（DDPM）做的事只有一件：**学会把噪声一步步"擦掉"**。前向过程是把图片逐渐毁成噪声，训练一个网络学会逆操作，生成就是从纯噪声开始反向走。

---

## 一、问题本质：生成 = 学一个分布

"生成图片"在数学上是：给定训练集（认为是分布 p_data 的样本），造一个能采样的 p_θ，使得新样本看起来属于同一分布。GAN 用对抗判别器隐式学，VAE 用变分下界显式学，**扩散模型用"迭代去噪"学**——它赢在训练稳定 + 质量上限。

## 二、前向过程：把图片毁掉（不需要学习）

对一张干净图 x₀，重复加高斯噪声 T 步（通常 T=1000）：

```
q(x_t | x_{t-1}) = N( x_t ; √(1-β_t) · x_{t-1}, β_t · I )
```

β_t 是预设的噪声表（从 1e-4 慢慢涨到 0.02），**没有任何参数要学**。

这条链有个关键性质：可以一步到位。令 α_t = 1-β_t，ᾱ_t = α₁α₂…α_t（累积乘积），则：

```
q(x_t | x_0) = N( x_t ; √ᾱ_t · x_0, (1-ᾱ_t) · I )
```

 meaning：**训练时不用真迭代 1000 步**——随机挑一个 t，直接从 x₀ 一条公式算出 x_t。这是 DDPM 能训得动的前提。当 t→T，ᾱ_T→0，x_t 退化成纯噪声。

## 三、训练：学"这段噪声是什么"

网络 ε_θ（U-Net 结构，输入 noisy 图和时刻 t，输出噪声预测）训练目标被化简成了惊人的形式：

```
loss = || ε - ε_θ( x_t, t ) ||²
```

即：把你掺进去的那个噪声原样预测回来，纯 MSE。理论推导从变分下界（ELBO）出发，逐项化简后所有 KL 项坍缩成这一项——这是 DDPM 论文最漂亮的地方：**一个从复杂推导里掉出来的极简损失**。

直觉理解：网络学的不是"图片长什么样"，而是**"在任意噪声程度上，往哪个方向擦能更干净一点"**。数学上这等价于学 score（∇log p(x)），即概率密度上升最快的方向——这就是 score matching 视角。

## 四、采样：从纯噪声反向走

生成时从 x_T ~ N(0,I) 出发，反复用训练好的网络走反向条件分布：

```
x_{t-1} = 1/√α_t · ( x_t - (1-α_t)/√(1-ᾱ_t) · ε_θ(x_t, t) ) + σ_t · z
```

每步减掉预测的噪声、再补一点随机性，走 1000 步得到 x₀。可以验证：训练目标是"预测噪声"，采样公式是"减掉预测的噪声"——**同一个网络，两种用法**。

## 五、两个决定性改进

**1. DDIM：把 1000 步砍到 50 步**
DDPM 采样是随机的（每步加噪声），DDIM 发现可以构造一族**确定性**的反向过程，不严格走马尔可夫链，从而允许跳步——t=1000 → 900 → 800 → … → 0。生成速度提升 20 倍，质量几乎不损失。今天所有生产级文生图都用 DDIM 及其后续（DPM-Solver 能到 20 步以内）。

**2. Latent Diffusion：别在像素上玩，去潜空间**
512×512×3 的图有 78 万维，直接扩散贵到不可用。Stable Diffusion 的做法：先用 VAE 把图压到 64×64×4 的潜空间（压缩 48 倍），**扩散过程全部在潜空间进行**，最后 VAE decoder 解码回像素。质量不降、成本降两个数量级——这是扩散模型能普及的工程前提。

**3. CFG：听懂提示词**
Classifier-Free Guidance：训练时随机丢弃文本条件（学无条件版），推理时外推：

```
ε = ε_uncond + w · ( ε_cond - ε_uncond )    # w 通常 5~8
```

放大"有条件和无条件的差异方向"= 沿着提示词的方向用力。w 越大越服从提示词、但越容易过饱和。

## 六、边界（对应"五道坎"第三章）

1. **慢**：即使 DDIM，仍要几十次网络前向，这是它 vs 自回归/掩码范式的固有权衡。
2. **不懂物理**：损失是分布拟合，没有动力学约束——生成的"水"不会遵守流体方程，"人"的手指会错。这不是数据问题，是**目标函数里没有物理项**的结构性缺陷。
3. **自纠错是它独有的优点**：多步迭代重画，早期错误有概率被洗掉——这点比自回归生成（错误单向传播）健康。

## 七、记忆卡

| 概念 | 一句话 |
|------|--------|
| 前向 | 预设噪声表把图毁成噪声，闭式公式一步到位 |
| 训练 | U-Net 预测"我掺的噪声"，纯 MSE |
| 采样 | 从纯噪声反向走，每步减掉预测噪声 |
| score 视角 | 学的是 log 密度的梯度=上升最快方向 |
| DDIM | 确定性反向 → 跳步加速 20 倍 |
| Latent Diffusion | 潜空间扩散，成本降 48 倍 |
| CFG | 条件与无条件的外推差 = 听话程度旋钮 |

一句话总结：**DDPM = 把"学分布"这个抽象问题，转化成"去噪"这个有闭式解、有稳定损失的监督学习问题。它赢了不是靠理论最优，是靠"能训得稳"。**
